## M1 目标

跑通「学 → 玩 → 错题 → 复习」完整闭环：框架 + 今日页 + 考点歼灭 + 连胜 + 错题本 + 第 1-3 章题库。

## 关键实现决策

- 全局命名空间 `GX`；题库 `window.GX_BANK`（避开 file:// 的 fetch 限制）
- 每日打卡规则（M1 适配）：完成「当日可完成任务」中的全部（M1 可完成 ≤2 项）即打卡；M2 起恢复「≥3 项」
- 错题出库条件：到期答对推进周期且记忆度 ≥100 时移出错题本
- 连胜冻结：漏卡自动消耗（每月 2 张，自然月补给）
- 玩家 HP 5、怪物 HP 20：答对 -2（连击≥3 追加 -1），答错 -1 且连击清零；HP 归零提前结算

## 验收标准

1. 双击 index.html 即可使用（file://，Chrome/Edge）
2. 今日页显示倒计时、任务、连胜、掌握度；完成考点歼灭后任务点亮、连胜延续
3. 考点歼灭可按章游玩，答错显示解析并自动入错题本
4. 错题页可见到期队列，「错题清扫」按间隔重复推进/回落
5. 档案页可导出/导入 JSON 存档、修改考试日期
6. 手机宽度（375px）与桌面宽度（≥768px）布局正常
